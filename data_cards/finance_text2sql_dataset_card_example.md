# 数据卡：finance_text2sql_eval_set

## 1. 数据集概览

| 属性 | 值 |
|---|---|
| 名称 | finance_text2sql_eval_set |
| 版本 | 0.1.0 |
| 规模 | 30 条（easy 8 / medium 12 / hard 10） |
| 用途 | 金融 Text2SQL 算子与流水线评测 |
| 许可 | Apache-2.0（随仓库分发） |

## 2. 数据构成

- 每条样本：`id`、`difficulty`、`question`（自然语言问题）、`schema`（模板化 DDL）、`gold_sql`（金标只读查询）。
- 覆盖模式：单表过滤/聚合、多表连接、比率计算（NULLIF 保护）、同比增速、窗口函数、子查询、分组排名。

## 3. 来源与合成说明

- schema 与公司名（甲/乙/丙/丁公司）均为**模板化虚构**，不含真实机构、真实客户或生产库结构；
- gold_sql 由人工编写并逐条核对语义一致性。

## 4. 已知局限

- 方言默认 sqlite，窗口函数/PERCENT_RANK 等在其他方言可能需要改写；
- 未覆盖 DML 场景（刻意排除：评测面向只读分析查询）；
- 规模较小，适合回归评测，不适合作为训练集。

## 5. 扩充与抽检要求

- `eval/expand_evalset.py` 可扩充至 200 条（离线模式生成占位骨架，需补齐 gold_sql）；
- **人工抽检 ≥20%**：重点核对 gold_sql 在目标方言下可执行、语义与 question 一致；
- 扩充样本发布前需更新本数据卡版本号与规模字段。
