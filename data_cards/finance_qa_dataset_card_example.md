## 2. 数据来源

- **来源类型**：模拟合成（LLM 生成 + 人工构造种子）
- **具体来源**：30 条人工种子样本（金标）+ 合成扩充样本
- **采集/生成时间范围**：2026-11
- **生成方式**：人工编写种子 → LLM 按题型/难度矩阵扩充 → 计划人工抽检 ≥20%
- **授权链**：全部为模拟数据，未使用任何真实公司未公开信息；真实公司名称一律以甲/乙/丙占位

## 3. 内容与口径

- **样本规模**：种子 30 条（当前随包），扩充目标 200 条
- **字段结构**：`id / qtype(factual|numeric|causal) / difficulty(easy|medium|hard) / source_text / question / answer / notes`
- **覆盖范围**：财报摘要、银行存贷与资产质量、券商经纪/投行、基金申赎与净值、保险赔付与成本率
- **口径说明**：金额单位统一为人民币亿元；比率保留题目要求精度；计算题给出过程
- **已知偏差**：行业覆盖偏银行/基金，缺少信托、期货场景（v0.2 补齐）

## 4. 敏感性与合规

- **个人信息**：不含（模拟数据）
- **敏感级别**：L1（公开模拟）
- **使用限制**：仅用于模型评测与研究，不构成投资建议；不得作为真实决策依据
- **再分发**：须连同本数据卡一起分发

## 5. 质量与维护

- **质量验证**：种子样本人工编写并双人复核；合成样本发布前抽检 ≥20% 核对数值一致性
- **已知错误**：暂无
- **维护计划**：随扩展包版本每季度更新；破坏性变更升级 minor 版本
- **撤回流程**：发现问题在 CHANGELOG 公告并于下一版本移除/修正
