# 数据卡模板（Data Card Template）

> 参考 DataFlow 社区数据卡实践与《数据要素》数据资源描述规范填写。
> 每个随包分发/生成的数据集**必须**附一份完成度 ≥90% 的数据卡。

## 1. 基本信息

| 字段 | 填写内容 |
|---|---|
| 数据集名称 | （如 finance-qa-eval-v0.1） |
| 版本与日期 | |
| 创建者（个人/团队） | |
| 联系方式 | |
| 许可证 | （CC BY-NC 4.0 / Apache-2.0 / 仅限本包使用） |
| 数据卡版本 | v0.1 |

## 2. 数据来源

| 字段 | 填写内容 |
|---|---|
| 来源类型 | 公开文件 / 授权采购 / 合成生成 |
| 具体来源 | （如：巨潮资讯网公开年报 / 模拟合成） |
| 采集/生成时间范围 | |
| 采集或生成方式 | （爬虫关键词 / LLM 合成 + 人工抽检比例） |
| 授权链说明 | （来源授权依据；公开信息的引用边界） |

## 3. 内容与口径

| 字段 | 填写内容 |
|---|---|
| 样本规模 | |
| 字段结构 | （字段名/类型/示例） |
| 覆盖范围 | （行业、时间段、题型分布） |
| 口径说明 | （财务数据口径、汇率/单位、复权处理等） |
| 已知偏差与空白 | |

## 4. 敏感性与合规

| 字段 | 填写内容 |
|---|---|
| 是否含个人信息 | 是/否（若否，说明脱敏方式） |
| 敏感级别 | （参考 JR/T 0197 金融数据分类分级） |
| 使用限制 | （不得用于投资建议/必须保留来源归因等） |
| 再分发条款 | |

|---|---|

| 已知错误清单 | |

| 弃用与撤回流程 | |
